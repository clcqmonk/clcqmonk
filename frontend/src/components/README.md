# RafflekTM360 Components

This directory contains React components for the RafflekTM360 platform.

## Components Overview

### HomePage.js
- Main landing page with hero section
- Raffle listings with filtering by category
- Recent winners showcase
- Age verification notices
- Raffle details and purchase modals

### UserDashboard.js
- User profile and account information
- Ticket purchase history
- Active raffle entries tracking
- Statistics overview (total tickets, spent amount, etc.)
- Account activity and security information

### AuthModal.js
- User registration and login modal
- Age verification (18+ requirement)
- Form validation and error handling
- Email verification flow
- Nepali phone number validation

### Admin.js (in parent directory)
- Admin dashboard for platform management
- Raffle CRUD operations
- Winner draw system
- User and ticket management
- Comprehensive analytics and reporting

### TermsPage.js
- Complete Terms & Conditions
- Legal requirements and eligibility
- Raffle rules and prize terms
- Responsible gaming guidelines
- Fair play and transparency policies

### PrivacyPage.js
- Privacy policy and data protection
- Information collection and usage
- Data security and retention policies
- User rights and contact information
- GDPR-style privacy protections

## Key Features

### Security & Compliance
- Age verification (18+ requirement)
- Responsible gaming notices
- Legal compliance for Nepal
- Data protection and privacy
- Secure authentication flow

### User Experience
- Mobile-responsive design
- Beautiful glassmorphism UI
- Real-time countdown timers
- Progress bars for ticket sales
- Intuitive navigation and flows

### Business Logic
- Cryptographically secure winner selection
- Email notifications (purchase confirmations, winner announcements)
- User account management
- Transparent draw records
- Comprehensive admin controls

## Usage

These components are designed to work together as a complete raffle platform:

1. **HomePage** - Main entry point for browsing raffles
2. **AuthModal** - User registration/login
3. **UserDashboard** - Account management and ticket tracking
4. **Admin** - Platform administration
5. **Legal Pages** - Terms and Privacy compliance

All components follow modern React patterns with hooks and functional components.
